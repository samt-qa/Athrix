## 1. ملخص تنفيذي

السوق منقسم إلى **ثلاث جزر منفصلة** لا يجمعها تطبيق واحد متقن:

| الجزيرة | الممثّل الأقوى | قوّته | ضعفه |
|---|---|---|---|
| بحث الأسماء الفوري | Everything، Cardinal، FSearch | سرعة خارقة (قراءة MFT) | لا يبحث داخل المحتوى، واجهة قديمة |
| بحث المحتوى | DocFetcher، Recoll، AnyTXT، Agent Ransack | يقرأ PDF/Office | بطيء في الفهرسة، واجهات جافّة |
| البحث الذكي/الدلالي | PixaFind، Dotient، LocalSpider، File Brain | "ابحث بالمعنى"، صور، OCR | منتجات ناشئة، ثقيلة، مغلقة، ضعيفة بالعربية |

**فرصتنا:** تطبيق واحد بمحرّك Rust أصلي يقدّم **الثلاثة في شريط بحث واحد**، بنتائج متدرّجة (الأسماء خلال ميلي ثوانٍ ← المحتوى ← الدلالي)، مع **أفضل دعم للغة العربية في هذه الفئة على الإطلاق**، وتصميم فاخر هادئ (عنابي/رصاصي/بيج).

## 2. تحليل السوق: ما الموجود؟

### 2.1 أدوات بحث الأسماء (Filename Search)

| الأداة | المنصة | الترخيص | آلية العمل | ملاحظات |
|---|---|---|---|---|
| **Everything** (voidtools) | Windows | مجاني (مغلق) | قراءة NTFS MFT + USN Journal | المعيار الذهبي للسرعة؛ لغة استعلام غنية؛ واجهة Win32 قديمة |
| **UltraSearch** (JAM) | Windows | مجاني/مدفوع | MFT | بديل قريب من Everything |

| **FSearch** | Linux | GPL | فهرس في الذاكرة | مستوحى من Everything |
| **FindCraft** | متعدد | GPL-3.0 | Rust + egui، MFT على ويندوز | مشروع مفتوح حديث |
| **OmniSearch** | Windows | مفتوح | Tauri v2 + Rust + C++، USN/MFT | يضيف كشف المكرّرات ومزامنة أندرويد عبر LAN |
| **SuperSearch** | متعدد | مفتوح | Rust، MFT + مسح متوازٍ | GUI + TUI + CLI |
| **UltraSearch (ToBeWin)** | متعدد | مفتوح | Tauri 2 + React + SQLite | بلا MFT؛ مراقبة تغييرات |

## 3. الفجوات والفرص

| # | الفجوة في السوق | فرصتنا |
|---|---|---|
| 1 | لا أحد يجمع الاسم + المحتوى + الدلالي بواجهة واحدة متقنة | **بحث موحّد متدرّج** في شريط واحد |
| 2 | العربية مهمَلة: لا تطبيع للهمزات، لا تجاهل للتشكيل، لا تعامل مع "ة/ه" و"ى/ي" | **محرّك عربي أصيل** (تفصيله في القسم 5.3) |
| 3 | خطأ لوحة المفاتيح الشائع: كتابة "lgt" وأنت تقصد "ملف" | **تصحيح تخطيط الكيبورد تلقائيًا** (عربي⇄إنجليزي) |
| 4 | واجهات Win32/Java قديمة أو "AI" ثقيلة بـ Electron | **Rust + Tauri**: خفيف، سريع، وجميل |
| 5 | أدوات الذكاء ترفع بياناتك أو مغلقة المصدر | **محلي 100%** بلا إنترنت افتراضيًا |
| 6 | التطبيقات تبدأ فارغة حتى تكتمل الفهرسة | **نتائج فورية من أول ثانية** (مسح حيّ + فهرسة تدريجية) |
| 7 | لا أحد يتيح فهرسه للوكلاء الذكيين بشكل نظيف | **خادم MCP اختياري** + CLI |

## 4. هوية المنتج وموقعه

- **الجملة التعريفية:** "اعثر على أي شيء في جهازك — بالاسم، بالمحتوى، أو بالمعنى — في لمحة."
- **الجمهور:** المحترفون، الباحثون، الطلاب، المبرمجون، المكاتب العربية ذات الأرشيف الضخم (PDF/Word).
- **المبادئ الخمسة:**
  1. **السرعة أولًا** — أي تفاعل < 16ms، النتائج الأولى < 50ms.
  2. **العربية مواطن من الدرجة الأولى** — RTL كامل، تطبيع، خطوط جميلة.
  3. **الخصوصية افتراضيًا** — لا شيء يغادر الجهاز.
  4. **الكيبورد أولًا، الفأرة مرحّب بها.**
  5. **هدوء بصري فاخر** — لا ضجيج، لا إعلانات، لا نوافذ مزعجة.

## 5. طرق البحث

التطبيق يحتوي **خمس طبقات بحث** تعمل بالتوازي وتُدمج نتائجها:

```
الاستعلام ──► [محلّل الاستعلام] ──┬──► ① محرّك الأسماء (ذاكرة)      ~1-30ms
                                  ├──► ② محرّك البيانات الوصفية      ~5-50ms
                                  ├──► ③ محرّك المحتوى (Tantivy)      ~20-150ms
                                  ├──► ④ المحرّك الدلالي (Vectors)    ~50-300ms
                                  └──► ⑤ محرّكات خاصة (مكرر، صور...)  عند الطلب
                                         │
                              [دمج + ترتيب (RRF) + Frecency] ──► النتائج تتدفق تدريجيًا
```

### 5.1 ① بحث الأسماء والمسارات
| الطريقة | مثال | ملاحظة |
|---|---|---|
| جزء من الاسم (Substring) | `تقرير` | الافتراضي |
| بادئة / لاحقة | `^report` / `2026$` | |
| حروف بدل (Wildcards) | `*.pdf`، `فاتورة_??` | |
| تعبيرات نمطية (Regex) | `regex:^IMG_\d{4}` | |
| ضبابي (Fuzzy) | `rprt` ⇠ `report.docx` | خوارزمية nucleo/fzf |
| بالمسار | `projects\ invoice` | المسافة = AND |
| الكلمات المختصرة (Acronym) | `mtr` ⇠ `MyTravelReport` | من CamelCase وحرف أول |
| حساسية الحالة/الكلمة الكاملة | `case:` `ww:` | |

**التقنية على ويندوز:** قراءة **NTFS Master File Table** مباشرةً (فهرسة مليون ملف في ثوانٍ) + متابعة **USN Journal** للتحديث اللحظي. على ماك: **FSEvents**، وعلى لينكس: **fanotify/inotify**. والبديل العام: مشي متوازٍ للمجلدات بمكتبة `ignore`/`jwalk`.

**بنية الفهرس:** مصفوفة أسماء مضغوطة في الذاكرة (String interning + شجرة أبوين) + فهرس n-gram للبحث الجزئي، مع بحث متوازٍ بـ `rayon` على كل الأنوية.

### 5.2 ② البحث بالبيانات الوصفية (Metadata Filters)
`size:>100mb` · `dm:today` · `dc:2026-01..2026-03` · `ext:pdf;docx` · `type:image` · `attrib:hidden` · `width:>1920` (صور) · `artist:` (صوت) · `camera:` (EXIF) · `pages:>50` (PDF) · `author:` (Office) · `tag:عمل`

### 5.3 ③ البحث داخل المحتوى (Full-text) — مع المحرّك العربي

**الصيغ المدعومة:** TXT/MD/كود · PDF · DOCX/XLSX/PPTX · ODT · RTF · EPUB · HTML · EML/MSG · ZIP (داخل الأرشيف) · الصور عبر OCR.

**قدرات الاستعلام:** عبارة دقيقة `"عقد الإيجار"` · منطقي `AND/OR/NOT` · قرب `"عقد إيجار"~5` · حقول `content:` `title:` · إبراز المقاطع المطابقة (Snippets).

**⭐ المحلّل العربي (Arabic Analyzer) — ميزتنا التنافسية الأولى:**

| الخطوة | قبل | بعد |
|---|---|---|
| إزالة التشكيل | مُحَمَّد | محمد |
| إزالة التطويل | الـــعربية | العربية |
| توحيد الألف | أ إ آ ٱ | ا |
| التاء المربوطة | مدرسة | مدرسه (فهرسة مزدوجة) |
| الألف المقصورة | مستشفى | مستشفي |
| الهمزات على الواو/الياء | مؤتمر، رئيس | (مطابقة مرنة) |
| الأرقام | ٢٠٢٦ ⇄ 2026 ⇄ ۲۰۲۶ | توحيد هندي/عربي/فارسي |
| التجذيع الخفيف (Light Stemming) | والمدارس، بالمدرسة | مدرس* (إزالة ال/و/ب/ف/ك/ل + لواحق ات/ون/ين/ها) |
| الحروف المتشابهة | ک→ك، ی→ي (فارسي/أردو) | توحيد |

**⭐ الأساس: مواصفة «نَصّ» (nass) — [samt-qa/nass](https://github.com/samt-qa/nass)**

بدل اختراع قواعد التطبيع من الصفر، يبني Athrix على مواصفة **nass v0.3** (رخصة MIT، ومتجهات الاختبار CC0). التطبيع جزء واحد من البحث العربي، والتجذيع وتصحيح الكيبورد طبقات نضيفها فوقه:

| ما تقدّمه nass | كيف يستفيد Athrix |
|---|---|
| **خريطة المواضع** `normalizeWithMap`: كل حرف مُطبَّع يُرجَع إلى موضعه في النص الأصلي | المقاطع (Snippets) والإبراز في المعاينة تظهر على **النص الأصلي بتشكيله** لا على نسخة مُطبَّعة. ويمكن لـ Tokenizer الخاص بـ Tantivy أن يعيد مواضع أصلية صحيحة |
| **3 مستويات** `clean` / `search` / `loose` | `clean` لأسماء الملفات المعروضة، و`search` للفهرسة الافتراضية، و`loose` يُفعّل بخيار «بحث متسامح» (ة↔ه، ؤ↔و، ئ↔ي) |
| صيغ العرض (ﷲ ﻻ ﷺ)، علامات القرآن، المحارف الخفية (RLM/LRM)، الحروف الفارسية، الأرقام الهندية/الفارسية | تغطّي حالات حقيقية في أسماء الملفات العربية وفي ملفات PDF المنسوخة من المصاحف وكتب التراث |
| **1,554 حالة اختبار مشتركة** + أداة مقارنة مع تنفيذ مستقل | تنفيذ Rust يُختبر على **نفس المتجهات** في CI، فيتطابق سلوكه بالحرف مع حزم Dart/TS/PHP |
| حزمة TS `@samt-qa/nass` (7.9KB، بلا اعتماديات) | الواجهة الأمامية (Tauri) تستخدمها مباشرةً لإبراز المطابقات في لوحة المعاينة، وتطابق المحرّك لأن الطرفين ينفّذان المواصفة نفسها |
| `nameKey` و `splitIsnad` | ميزة إضافية لاحقة: **وضع «المكتبة الشرعية»** لمن لديه أرشيف حديث/تراث (بحث بالراوي، فصل السند عن المتن) — P3 |

**ما لا تغطّيه nass (نضيفه نحن في Athrix):** التجذيع الخفيف، وتصحيح تخطيط الكيبورد، والفرانكو، والتوحيد مع البحث الضبابي.

> ⚠️ لا توجد حزمة Rust لـ nass حاليًا (Dart · TS · PHP فقط) ⇠ **المهمة الأولى في M3 هي كتابة تنفيذ Rust رابع يمرّ على كل المتجهات.**

**⭐ تصحيح تخطيط لوحة المفاتيح:** إن كتب المستخدم `hgjrvdv` ولم توجد نتائج، يقترح فورًا: "هل تقصد **التقرير**؟" (والعكس: `شسيب` ⇠ `asdf`).

**⭐ الفرانكو والترجمة الصوتية (اختياري):** `mo7amed` ⇠ `محمد`.

### 5.4 ④ البحث الدلالي (بالمعنى)
- اكتب: *"عقد إيجار الشقة في الرياض"* ⇠ يجد `lease_final_v3.pdf` حتى لو لم تتطابق الكلمات.
- **النموذج المقترح:** `multilingual-e5-small` أو `bge-m3` (يدعمان العربية فعليًا) عبر **fastembed-rs/ONNX Runtime** — على CPU، بدون إنترنت.
- **الصور:** نموذج CLIP متعدد اللغات ⇠ "صورة غروب على البحر".
- **الدمج الهجين:** Reciprocal Rank Fusion بين نتائج BM25 (Tantivy) ونتائج المتجهات.
- **التخزين:** فهرس HNSW (مثل `usearch` أو `lancedb`).
- يعمل **فقط على المجلدات التي يختارها المستخدم** (المستندات، سطح المكتب...) لتوفير الموارد.

### 5.5 ⑤ محرّكات خاصة
| المحرّك | الفكرة | التقنية |
|---|---|---|
| كشف المكرّرات | ملفات متطابقة تمامًا | الحجم ← هاش جزئي ← BLAKE3 كامل |
| الصور المتشابهة | نسخ معدّلة/مصغّرة من نفس الصورة | Perceptual Hash (pHash/dHash) |
| الملفات الكبيرة | ما الذي يلتهم القرص؟ | تجميع الأحجام + Treemap |
| الملفات المنسيّة | لم تُفتح منذ سنة | `da:<2025` |
| الأخيرة/الأكثر استخدامًا | Frecency | سجلّ محلي للفتح |
| البحث باللغة الطبيعية (اختياري) | "ملفات PDF الكبيرة من الشهر الماضي" ⇠ `ext:pdf size:>10mb dm:lastmonth` | قواعد + نموذج LLM محلي صغير اختياري |

## 8. المعمارية التقنية

### 8.1 القرار الأهم: إطار الواجهة

| الخيار | المزايا | العيوب | القرار |
|---|---|---|---|
| **Tauri 2** (Rust + Web UI) | تصميم حرّ وجميل، **دعم عربي/RTL ممتاز** (المتصفح يتولّى تشكيل الحروف)، حجم صغير (~10MB)، نظام plugins | طبقة WebView | ✅ **المُوصى به** |
| Slint | أصلي، أداء ممتاز | دعم RTL/العربية أقل نضجًا | بديل مستقبلي |
| egui | بسيط جدًا وسريع | تشكيل العربية ضعيف، شكل "أداة مطوّرين" | ❌ |

**الواجهة الأمامية داخل Tauri:** **SolidJS** أو **Svelte 5** (أخف من React وأسرع في القوائم الطويلة) + **TypeScript** + قوائم افتراضية (Virtualized List) لعرض مليون نتيجة بسلاسة.

### 8.2 تقسيم المشروع (Cargo Workspace)

```
app/
├── crates/
│   ├── core/          # الأنواع المشتركة، الإعدادات، الأخطاء
│   ├── fs-index/      # فهرس الأسماء في الذاكرة + المشي + MFT/USN + المراقبة
│   ├── query/         # محلّل لغة الاستعلام → AST → خطة تنفيذ
│   ├── nass/          # تنفيذ Rust لمواصفة nass v0.3 (تطبيع + خريطة مواضع) — يُختبر على متجهاتها
│   ├── text-ar/       # فوق nass: تجذيع خفيف، تصحيح الكيبورد، فرانكو، Tokenizer لـ Tantivy
│   ├── extract/       # مستخرجات المحتوى (PDF, Office, EPUB, OCR...)
│   ├── content-index/ # Tantivy + جدولة الفهرسة الخلفية
│   ├── semantic/      # التضمين (ONNX) + فهرس المتجهات + الدمج الهجين
│   ├── ranking/       # RRF + Frecency + إشارات الترتيب
│   ├── store/         # SQLite: الوسوم، السجلّ، البحوث المحفوظة، حالة الفهرسة
│   ├── daemon/        # خدمة خلفية (اختيارية) تحتفظ بالفهرس في الذاكرة
│   └── cli/           # واجهة سطر الأوامر
├── apps/
│   └── desktop/       # Tauri 2 + SolidJS/Svelte
└── docs/
```

### 8.3 تدفّق البيانات
1. **الإقلاع:** تحميل لقطة الفهرس من القرص (mmap) ⇠ جاهز خلال < 300ms.
2. **التحقّق:** قراءة USN Journal منذ آخر تشغيل ⇠ تطبيق الفروقات فقط.
3. **الفهرسة الخلفية للمحتوى:** طابور أولويات (الملفات الأحدث والمجلدات المهمة أولًا)، **يتوقف تلقائيًا** عند استخدام الجهاز بكثافة أو العمل على البطارية.
4. **البحث:** كل محرّك يبثّ نتائجه عبر قناة (channel) ⇠ الواجهة تستلم دفعات تدريجية عبر Tauri events.

|---|---|

## 11. الخصوصية والأمان
- 🔒 **لا اتصال بالإنترنت افتراضيًا**؛ النماذج تُحمَّل مرة واحدة بإذن صريح وتُتحقَّق بالهاش.
- 🔒 استثناء تلقائي للمسارات الحساسة (مجلدات كلمات المرور، `.ssh`، ملفات `.env`) من فهرسة المحتوى.
- 🔒 تشفير اختياري للفهرس على القرص.
- 🔒 خادم MCP معطّل افتراضيًا، وعند تفعيله: قائمة مجلدات مسموحة + قراءة فقط.
- 🔒 خدمة MFT المساعدة بأقل الصلاحيات، تتواصل عبر Named Pipe محمي.
- 🔒 بلا تتبّع (Telemetry) إلا بموافقة صريحة ومجهولة.
