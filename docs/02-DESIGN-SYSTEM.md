## 1. الفلسفة البصرية

| المبدأ | التطبيق |
|---|---|
| **العنابي نادر وثمين** | لا يتجاوز ~10% من مساحة الشاشة: الشعار، المؤشر، العنصر المحدّد، الأزرار الرئيسية، إبراز المطابقات |
| **البيج هو الورق** | الخلفية الرئيسية دافئة، لا أبيض ناصع أبدًا |
| **الرصاصي هو الحبر الهادئ** | النصوص الثانوية، الحدود، الفواصل، الأسطح الثانوية |
| **المحتوى هو البطل** | النتائج والمعاينة تأخذ المساحة، والكروم (Chrome) يختفي |
| **الكثافة القابلة للضبط** | وضع "مريح" للعامة، ووضع "مضغوط" للمحترفين |

## 4. الطباعة والخطوط

### 4.1 العائلات
| الدور | العربية | اللاتينية | السبب |
|---|---|---|---|
| واجهة (UI) | **IBM Plex Sans Arabic** | **IBM Plex Sans** أو **Inter** | عائلة متناسقة الوزن بين اللغتين، واضحة في الأحجام الصغيرة |
| عناوين مميّزة (Display) | **Readex Pro** أو **Noto Kufi Arabic** | نفسها | طابع كوفي حديث للشعار والعناوين الكبيرة فقط |
| مسارات وكود | — | **JetBrains Mono** / **Cascadia Code** | المسارات تُعرض LTR دائمًا |

> الخطوط تُضمَّن داخل التطبيق (لا تحميل من الإنترنت) — كلها برخصة OFL.

### 4.2 السُّلّم الطباعي
| الرمز | الحجم/الارتفاع | الوزن | الاستخدام |
|---|---|---|---|
| `display` | 28 / 36 | 600 | شاشة الترحيب |
| `title-lg` | 20 / 28 | 600 | عناوين الصفحات |
| `title` | 16 / 24 | 600 | عناوين الأقسام، اسم الملف في المعاينة |
| `search` | 18 / 28 | 400 | **نص شريط البحث** |
| `body` | 14 / 22 | 400 | النص العام، اسم الملف في النتائج |
| `body-strong` | 14 / 22 | 600 | المطابقة المبرَزة |
| `caption` | 12 / 18 | 400 | المسار، الحجم، التاريخ |
| `micro` | 11 / 16 | 500 | الشارات، اختصارات الكيبورد |

**ملاحظة عربية:** ارتفاع السطر للعربية أكبر بـ ~10% من اللاتينية (الحروف الصاعدة والنازلة والتشكيل). لا تقلّ عن `line-height: 1.55` لأي نص عربي.

## 5. المسافات والشبكة

- **الوحدة الأساسية:** 4px. السلّم: `4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64`.
- **ارتفاع صف النتيجة:** مريح `44px` · مضغوط `32px` · بطاقات (للصور) `160px`.
- **ارتفاع شريط البحث:** `56px` (النافذة الكاملة) · `64px` (النافذة المنبثقة).
- **الزوايا:** `--radius-sm: 6px` (شارات، Kbd) · `--radius-md: 10px` (أزرار، حقول، صفوف) · `--radius-lg: 14px` (بطاقات، لوحات) · `--radius-xl: 20px` (النافذة المنبثقة).

## 6. الظلال والعمق

ظلال **دافئة** (مشوبة بالعنابي العميق) بدل الأسود الرمادي:

```css
--shadow-sm: 0 1px 2px rgb(74 15 26 / 0.06);
--shadow-md: 0 4px 12px rgb(74 15 26 / 0.08), 0 1px 3px rgb(74 15 26 / 0.06);
--shadow-lg: 0 18px 48px rgb(74 15 26 / 0.14), 0 4px 12px rgb(74 15 26 / 0.08);
/* الداكن: ظلال سوداء أعمق + حد علوي فاتح 1px بدل الظل */
```

**النافذة المنبثقة:** خلفية شبه شفافة مع `backdrop-filter: blur(24px)` (Mica/Acrylic على ويندوز 11، Vibrancy على ماك) فوق `--bg-surface` بنسبة 85%.

## 7. الحركة

| الرمز | المدة | المنحنى | الاستخدام |
|---|---|---|---|
| `--motion-instant` | 80ms | `ease-out` | Hover، تحريك التحديد |
| `--motion-fast` | 140ms | `cubic-bezier(.2,.8,.2,1)` | ظهور القوائم، تبديل التبويبات |
| `--motion-base` | 220ms | `cubic-bezier(.2,.8,.2,1)` | فتح لوحة المعاينة |
| `--motion-enter` | 180ms | `cubic-bezier(.16,1,.3,1)` | ظهور النافذة المنبثقة (scale .98→1 + fade) |

**قواعد:**
- النتائج **لا تتحرّك** عند وصولها (لا قفزات) — فقط تلاشٍ خفيف 80ms للدفعات الجديدة.
- مؤشر التحديد ينزلق بنعومة بين الصفوف.
- احترام `prefers-reduced-motion` ⇠ تعطيل كل الحركات غير الضرورية.
- مؤشر الفهرسة: خط رفيع عنابي متحرّك أسفل شريط البحث (لا دوائر دوّارة).

## 8. الأيقونات

- **المكتبة:** **Lucide** (أو Phosphor) — خطيّة، سُمك `1.75px`، حجم `16/20/24`.
- أيقونات أنواع الملفات: مخصّصة بشكل "ورقة مطويّة الزاوية" + شارة لون النوع (القسم 2.5).
- الأيقونات الاتجاهية (أسهم، رجوع) **تنعكس في RTL**؛ أيقونات الكائنات (ملف، بحث، ساعة) **لا تنعكس**.

### الشعار (توجيه)
علامة بسيطة: **عدسة بحث** يتقاطع داخلها **حرف عربي/لاتيني** أو شكل **نقطة/أثر قدم** — بالعنابي `#7A1F2E` على البيج، وأيقونة التطبيق مربعة بزوايا `22%` بخلفية عنابية متدرّجة (`#93293A → #5E1522`) ورمز بيج `#F5EFE6`.

### 9.2 النافذة الكاملة (Workspace)
```
┌────────────┬─────────────────────────────────┬──────────────────┐
│  الشعار     │ 🔍 شريط البحث + شرائح الفلاتر      │                  │
│            ├─────────────────────────────────┤   لوحة المعاينة   │
│ ★ المفضّلة  │  الاسم ▾   المسار   الحجم  التاريخ │   (PDF/صورة/نص)  │
│ 🕘 الأخيرة  │  ─────────────────────────────  │                  │
│ 🔖 محفوظة   │  صفوف النتائج (قائمة افتراضية)     │  ▸ البيانات       │
│ 🏷 الوسوم   │                                 │    الوصفية        │
│ 💽 الأقراص  │                                 │  ▸ الأفعال        │
│            │                                 │                  │
│ ⚙ الإعدادات │  شريط الحالة: مُفهرس 1.2M ملف ✓     │                  │
└────────────┴─────────────────────────────────┴──────────────────┘
   240px              مرن (min 480px)                  360–520px
```
- في RTL: الشريط الجانبي على **اليمين** والمعاينة على **اليسار** (انعكاس كامل).
- مفتاح فتح المعاينة هو السهم المتجه نحوها: **←** في العربية و**→** في الإنجليزية (قرار المستخدم 2026-11-21).
- الشريط الجانبي قابل للطيّ إلى أيقونات (`64px`).

### 9.3 الشاشات الأخرى
| الشاشة | ملاحظات التصميم |
|---|---|
| **الترحيب (Onboarding)** | 3 خطوات: اختيار المجلدات ⇠ مستوى الفهرسة (أسماء / محتوى / ذكي) ⇠ الاختصار. رسم خطّي عنابي بسيط |
| **الإعدادات** | تبويبات عمودية: عام، الفهرسة، المحتوى، الذكاء، المظهر، الاختصارات، الخصوصية، حول |

| **المكرّرات** | مجموعات قابلة للطي، معاينة جنبًا إلى جنب، "احتفظ بالأحدث" |

| **ProgressLine** | 2px أسفل شريط البحث، `--accent` بتدرّج متحرّك |
| **Badge (نوع الملف)** | 11px، خلفية لون النوع @ 12%، نص لون النوع |
| **Tabs** | خط سفلي 2px `--accent` للنشط |
| **Toggle / Checkbox** | تشغيل = `--accent` |
| **Scrollbar** | رفيع 8px، `gray-300` ⇠ `gray-400` عند Hover، يختفي عند الخمول |

## 11. العربية و RTL

- اتجاه الواجهة يتبع لغة الواجهة (`dir="rtl"`)، مع إمكانية الاختيار يدويًا.
- **استخدم الخصائص المنطقية دائمًا:** `margin-inline-start` بدل `margin-left`، `padding-inline`، `inset-inline-start`، `border-inline-start`.
- **المسارات وأسماء الامتدادات والأحجام تُعرض داخل `<bdi dir="ltr">`** لتجنّب تشوّه `D:\العمل\file.pdf`.
- **شريط البحث `dir="auto"`**: يتّجه حسب أول حرف يكتبه المستخدم.
- الأرقام: الإعداد الافتراضي أرقام عربية غربية (0-9) مع خيار للأرقام الهندية (٠-٩).
- التواريخ النسبية بالعربية الصحيحة نحويًا: "قبل دقيقة / دقيقتين / 3 دقائق / 11 دقيقة" (استخدم `Intl.RelativeTimeFormat('ar')` و `Intl.PluralRules`).
- اختصارات الكيبورد تعمل بغض النظر عن تخطيط اللغة النشط (اعتمد على `KeyboardEvent.code` لا `key`).
- اختبر دائمًا بنصوص طويلة: "استراتيجية_التحول_الرقمي_للمؤسسات_الحكومية_النسخة_النهائية_المعتمدة.docx".

## 12. إمكانية الوصول

- كل الألوان النصية ≥ AA (انظر 2.6).
- تنقّل كامل بالكيبورد: `↑↓` النتائج، `Tab` بين المناطق، `→/←` (حسب الاتجاه) للمعاينة، `Esc` للإغلاق.
- `focus-visible` واضح دائمًا (حلقة عنابية).
- قائمة النتائج بدور `listbox` و `aria-activedescendant`، وإعلان عدد النتائج بـ `aria-live="polite"`.
- دعم تكبير الخط حتى 200% دون كسر التخطيط.
- وضع تباين عالٍ يحترم إعدادات النظام (`forced-colors`).

## 14. ما يجب تجنّبه
- ❌ خلفيات عنابية كبيرة (تُتعب العين وتُفقد اللون قيمته).
- ❌ الأبيض الناصع `#FFFFFF` كخلفية رئيسية، والأسود الخالص `#000000` كنص.
- ❌ الرماديات الباردة المزرقّة (تتنافر مع البيج).
- ❌ التدرّجات اللونية الصاخبة والزجاجيات المبالغ فيها.
- ❌ الخطوط العربية المزخرفة في الواجهة (ديواني/رقعة) — فقط للشعار إن لزم.
- ❌ `margin-left/right` الثابتة (تكسر RTL).
- ❌ دوائر التحميل الدوّارة في منتصف النتائج.
- ❌ أكثر من 3 أوزان خط في الشاشة الواحدة.
