## 5. 🧹 ديون تقنية وتحسينات صغيرة

| البند | التفاصيل |
|---|---|
| استثناءات الفهرسة مكرّرة | قائمة المجلدات المستثناة الافتراضية موجودة في الأداة وفي التطبيق؛ تُنقل إلى `fs-index` |
| منطق تحويل معرّف النتيجة مكرّر | نسخة في `library.rs` وأخرى في `commands.rs` (`resolve_entry`)؛ تُوحَّد |
| مفاتيح ترجمة غير مستخدمة | `drives.button`، `drives.cancel`، `preview.failed`، `preview.reason.pdf` |
| عامل PDF في `target/debug` | `cargo build --workspace` يبني نسخة بلا PDF بجانب التطبيق ويطغى على النسخة المجهّزة. التطبيق المثبّت لا يتأثر؛ في التطوير شغّل `npm run worker` بعد أي بناء شامل |
| أخطاء قراءة البيانات الوصفية عند المشي على C: | أكثر من 2000 خطأ «os error 1920» في مجلدات النظام؛ تُخفض إلى مستوى debug أو تُستثنى تلك المسارات |
| تكلفة ربط نتائج المحتوى بالأسماء (`PathLookup`) | تصل إلى 10,000 مرة في استعلام AND؛ صغيرة لكن لم تُقس |
| المقطع في المستندات الكبيرة | قد يختلف عن السابق في المستندات > 64KB إذا كان أكثف تجمّع للكلمات بعد أول نافذة فيها مطابقة |
| «إخراج الجهاز بأمان» قد يُرفض | مراقبة القرص الخارجي تُبقي مقبضًا مفتوحًا عليه؛ الحل رسائل `DBT_DEVICEQUERYREMOVE` لإغلاق المراقبة قبل الإخراج |
| تذكّر الأقراص الخارجية لجلسة واحدة | بعد إعادة التشغيل لا يظهر القرص المفصول كـ«غير موصول» حتى يُوصل مجددًا |
| اقتراح «هل تقصد؟» ما زال 36–46ms | لم يعد يؤخّر الكتابة، لكن عدّ المطابقات التقريبية يمكن أن يتوقف عند الحد بدل ترتيب الفهرس كله |
| `fuzzy:` بعدة كلمات | لا تستفيد من حد الدرجة الأدنى بعد |
| ذاكرة البصمات لا تُنظَّف | `hashes/dupes.sqlite3` و`phash.sqlite3` تحتفظ بصفوف الملفات المحذوفة حتى يُعاد حسابها |
| ذاكرة خادم MCP | يحمّل لقطة الأسماء كاملة (≈ 540MB على هذا الجهاز) عند أول بحث ولا يفرّغها عند الخمول |
| حدود الصور المتشابهة | لا HEIC/AVIF، واتجاه EXIF مُهمل (النسخة المدوّرة لا تُطابق) |
| حدود اللغة الطبيعية | التواريخ `dm:` فقط (لا `dc:`/`da:` بعد)، ولا «ملفات كبيرة» بلا رقم؛ وتجاهل الاقتراح لا يُحفظ بعد إعادة التشغيل |
| `dupe:` مع `content:` | مرفوض حاليًا برسالة واضحة بدل دعمه |
| خطأ في حزمة nass (upstream) | `normalize("ﹱ")` يعطي «ـ» ثم يختفي عند التطبيع الثاني (أشكال العرض U+FE70..FE7F)؛ التطبيع ليس متكرّر الثبات لهذه الأحرف. يُصلَح في مستودع nass لا في Athrix |
| نسخة احتياطية لمفتاح التحديث | `%USERPROFILE%\.athrix\updater.key`؛ إن ضاع لن تقبل النسخ المثبّتة أي تحديث |
